this project is for initiating commands adding file in folder and creating repo.
first we have to create a folder on the desktop.
open that folder in VS code and create file in it.
command are as follow:
                      git init
                      git add .
                      git commit -m "msg"
                      git branch -M main
                      git remote add origin **URL of repo**
create repo into github and copy URL of that repository and paste over "url".
                      git push -u origin main
for adding content in the file: git add .
                                git commit -m "changes done"
                                git push
